# Colours for the facility taxonomy

Greens for off-street, blues for on-street separated or marked lanes,
oranges for shared facilities, greys for the rest.

## Usage

``` r
cl_palette()
```

## Value

A named character vector of hex colours over
[`cl_facility_levels()`](https://mjorden.github.io/cyclelanes/reference/cl_facility_levels.md).
